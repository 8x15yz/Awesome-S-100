# Contributing to Awesome S-100

Thank you for considering a contribution. Please read these guidelines before opening a PR.

## What belongs here

- Resources directly related to IHO S-100 and its family of product specifications
- Open-source tools, libraries, or datasets that implement or support S-100
- Official documents, registries, and stable reference pages from IHO, IALA, IMO, and related bodies
- Learning materials: seminar recordings, papers, tutorials with lasting relevance

## What does not belong here

- S-57 or other legacy hydrographic standards (unless explicitly bridging to S-100)
- General marine GIS or nautical charting tools unrelated to S-100
- Blog posts, news articles, or ephemeral content
- Broken or unmaintained links (check before submitting)
- IHO/IALA document PDFs hosted directly — link to the official registry entry or stable page instead

## Format rules

- Entries follow the pattern: `- [Name](URL) — One sentence description.`
- Description starts with a capital letter and ends with a period.
- Keep descriptions factual and neutral; avoid marketing language.
- For product specification tables, use the column schema defined in [CURATION.md](CURATION.md).

## Link guidelines

- Prefer registry entries and canonical landing pages over direct PDF links.
- Direct PDF links break on every revision — use them only as a secondary `[PDF]` link alongside a stable primary link.
- Test that all links resolve before submitting.

## Submitting a PR

1. Fork the repository and create a branch from `main`.
2. Make your addition in the appropriate section.
3. Verify all links are live.
4. Open a PR with a brief description of what you're adding and why it belongs.

## Updating existing entries

If an edition number, status, or link has changed, include a reference (IHO publication notice, GI Registry update) in the PR description.
